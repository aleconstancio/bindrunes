# Marketing Site Template

A landing page with hero section, features grid, pricing table, FAQ accordion, and CTA.

## How to Run

```bash
bun install
bun run dev
```

## Key Components Used

- `Card` — Feature cards and pricing cards with header snippets
- `Button` — CTA buttons and navigation
- `Badge` — Version badge and pricing badges
- `Separator` — Section dividers
- `Accordion`, `AccordionItem` — FAQ section with `trigger` and `children` snippets

## What It Demonstrates

- Flat Card API with `{#snippet header()}` for feature icons and pricing headers
- Accordion API with `trigger` snippet for FAQ questions and default children for answers
- Multiple page sections with consistent styling
- Sticky navigation header
- Responsive grid layouts for features and pricing
