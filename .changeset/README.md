# Changesets

Hello and welcome! This folder has been automatically generated by
[`@changesets/cli`](https://github.com/changesets/changesets)) on behalf of the
maintainers of this monorepo. To get started:

1. Each pull request should add a new Markdown file inside this folder named
   after the change. Use the format `<change-name>.md`.

2. The file content should look like:

   ```md
   ---
   "package-name": minor
   ---

   A short description of the change.
   ```

   Valid `bump` types are `patch`, `minor`, and `major`.

3. Changesets will be validated, versioned, and a changelog generated by the
   `release` workflow when PRs are merged into `main`.

For more details, see the [Changesets documentation](https://github.com/changesets/changesets).
